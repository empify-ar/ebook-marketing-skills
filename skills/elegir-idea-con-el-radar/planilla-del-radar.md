# Planilla para comparar ideas del Radar

Una fila por idea. Las cuatro primeras columnas se copian tal cual de lo que la persona pegó del Radar; si un dato no vino, queda "no lo pegó". Las tres siguientes las contesta ella.

| Idea (como figura en el Radar) | País elegido y rótulo | Fecha de la medición (¿vigente?) | Línea de origen, con su fecha | ¿Sabe o tiene material propio? | ¿Llega a ese público? ¿Por dónde? | Su versión: qué la hace distinta |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |

"Vigente" quiere decir que la medición tiene 30 días o menos a hoy. Si no, se lee como "Sin medir".

## Lectura

- Idea que va primero y por qué (separando lo que dice el Radar de lo que aporta la persona): ____
- Segunda opción, si hay: ____
- Lo que el Radar no puede decir de estas ideas: si hay compradores, a qué precio, si eligen esto frente a lo gratis.
- Próximo paso (uno): `idea-de-ebook`, `validar-idea-de-ebook` o "Crear mi versión" en el panel: ____

## Frases que no van

| No | Sí |
|---|---|
| "Esta idea se vende" | "Esta idea se anuncia en Brasil desde hace 120 días (al 24 de octubre de 2026)" |
| "Está validada" | "En Argentina, al [fecha], hay 2 anunciantes con esa frase" |
| "Nadie la hace: es tu oportunidad" | "Esa semana nadie la anunció en Meta; no sabemos si hay demanda" |
| "Mucha competencia: descartala" | "Hay 10 o más anunciantes: si la elegís, va con un ángulo propio" |
