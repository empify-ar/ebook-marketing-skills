# Planilla: lo que queda por venta

Completala con los números reales de la persona. Si un dato no está, queda "sin dato": no se estima.

## 1. Datos

| Concepto | Valor | De dónde sale |
|---|---|---|
| Precio de venta (pesos) | | Lo decide la persona |
| Comisión de la plataforma de venta (% por venta) | | Página oficial de la plataforma (enlace y fecha) |
| Tarifa del medio de pago (%) | | Página oficial o su propia cuenta de cobro (enlace y fecha) |
| Impuestos sobre la venta o la tarifa | | Su situación impositiva / quien le lleva los impuestos |
| Costos propios por venta (por ejemplo, un bono con costo) | | La persona |
| Gastos fijos del período (anuncios, herramientas) | | La persona |

## 2. Cuenta

| Paso | Operación | Resultado |
|---|---|---|
| A | Precio × comisión de la plataforma | |
| B | Precio × tarifa del medio de pago (más impuestos que correspondan) | |
| C | Costos propios por venta | |
| D | **Lo que queda por venta** = precio − A − B − C | |
| E | Ventas necesarias para cubrir los gastos fijos = gastos fijos ÷ D | |
| F | Lo que querés ganar por venta | |
| G | Máximo a pagar por conseguir una venta = D − F | |

## 4. Cómo leerla

- Si D es menor o igual a cero, ese precio pierde plata en cada venta: no se sigue sin cambiar algo.
- Si E es mucho mayor que las ventas que la persona cree posibles en su canal, el problema es del precio o del gasto fijo, no de la página.
- G es un techo, no un objetivo: pagar hasta ahí por una venta significa no ganar nada con ella.
- Esta cuenta no dice si habrá ventas. Dice cuántas hacen falta para que cierre.
