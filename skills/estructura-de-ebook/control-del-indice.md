# Control de calidad del índice

Marcá cada punto con pasa o no pasa. Donde no pasa, escribí el arreglo, no solo el problema.

## A. La promesa

- [ ] Está en una sola frase.
- [ ] Nombra a quién y qué va a poder hacer, con un verbo que se ve.
- [ ] Se puede comprobar: alguien puede decir "lo logré".
- [ ] No promete ingresos, plazos mágicos ni cambios de vida.
- [ ] No usa "definitivo", "completo", "fácil" o "rápido" sin algo que lo respalde.

## B. El camino

- [ ] Los capítulos siguen el orden que haría una persona real de cero al resultado.
- [ ] El primer capítulo ya deja algo hecho o entendido.
- [ ] Lo que se necesita tener antes de empezar está dicho antes del paso 1.
- [ ] Hay un lugar para "qué hago si no me sale" cerca de donde suele fallar.
- [ ] No hay saltos: ningún capítulo da por sabido algo que nadie explicó antes.

## C. Cada capítulo

- [ ] El título dice qué hace o qué responde (no "Introducción" ni "Conceptos generales").
- [ ] Se puede resumir en una frase que empieza con un verbo.
- [ ] Esa frase no se parece a la de otro capítulo (si se parece, fusionar).
- [ ] No necesita "y" para describirse (si la necesita, partir).
- [ ] Lleva algo para hacer o mirar: ejemplo, plantilla, lista, ejercicio, no solo explicación.
- [ ] Alguno responde cada objeción que apareció al probar la idea.

## D. Alcance

- [ ] Si saco este capítulo, la promesa deja de cumplirse (si no, sobra).
- [ ] Lo que quedó afuera está anotado con destino: bono, otro libro, descartado.
- [ ] El largo total coincide con el tiempo de lectura o práctica que se quiere ofrecer.
- [ ] Ningún capítulo es mucho más largo o más corto que el resto sin una razón.

## E. Para la página de venta

- [ ] Con los títulos de los capítulos se puede armar la lista de "qué trae" sin inventar nada.
- [ ] Hay al menos un capítulo, página o plantilla que se pueda mostrar como muestra del interior.
- [ ] Se puede decir para quién no es, porque el índice deja claro lo que no cubre.
